## Instalación de R

Se ha utilizado `R 4.2.1 Patched`, y que se puede descargar en el siguiente [link](https://cran.r-project.org/bin/windows/base/R-4.2.1patched-win.exe).

## Instalación del entorno virtual en Anaconda

Instalación entorno virtual con Anaconda:

```bash
conda create -n r-basic python=3.7
```

```bash
pip install -r requirements.txt
```

o bien:

```bash
conda env create -f r-basic.yml
```
